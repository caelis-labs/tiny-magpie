# tiny-magpie 功能复核清单（待人工决定）

本清单是建议，不更改现有裁剪契约。新一轮裁剪须在人工确认后实施；本轮已授权的是安装体验和 Tiny 自身更新。保留多 Provider、原版模型协议、Provider/网关插件协议、美观易用 GUI 和持续跟随上游这五项约束。

## 证据与分级

- 实机：2026-10-19，正在运行的 0.1.2，`/Volumes/tiny-magpie/tiny-magpie.app/Contents/MacOS/tiny-magpie`。只浏览供应商/添加面板、路由、网关、用量、插件、设置五个子页；没有修改账号或业务设置、安装插件、手动刷新额度、执行真实模型请求。页面自身的正常后台读取仍可能发生。结束后恢复隐私页。
- Tiny 源码基线：`c0b24cdd22a20dc4d330a30f7bef45e36370460f`；已集成上游：`d783df46cbac9021e26a6bd71ca0b55544552eb2`。
- 重新对齐的上游快照：[`c483feadfd88a5b8de8541de0567f3856822bde5`](https://github.com/yetone/magpie/commit/c483feadfd88a5b8de8541de0567f3856822bde5)，2026-10-19 05:42 UTC。查看其 [README](https://github.com/yetone/magpie/blob/c483feadfd88a5b8de8541de0567f3856822bde5/README.md) 和 [GUI 设置定义](https://github.com/yetone/magpie/blob/c483feadfd88a5b8de8541de0567f3856822bde5/internal/gui/assets/index.html)。这是功能比较，**没有把该快照合并进 Tiny**。认证、模型和额度修复仍按周跟踪；不能把基线之后的上游修复称为已拥有。

- 人工栏可填写「保留 / 收进高级 / 删除入口 / 删除实现 / 待定」。删除入口与删除后端必须分开验收。

## 实机优先修整项

1. **模型设置**：实机出现「图像 / 联网搜索 / 回复」三个无内容标题；只保留仍有功能的分组。停用模型说明提及已裁掉的会话、子 Agent、决策模型，必须改成实际承诺。
2. **网络与共享**：实机出现空「GITHUB」标题；端口说明仍承诺自动修改 Agent 配置，Tiny 已不做，应删承诺。
3. **隐私**：将 A01–A03 和 U12 拆开；建议默认不设单独隐私大页，账号发现归供应商，打码归列表工具栏，脱敏归高级。
4. **路由**：实时大图、路由组列表和全局显示名称设置同屏，首次使用难以找到建组；建议以组列表为主，实时排障折叠。
5. **插件**：避免「不是人人都需要」的说明下出现网关、路由等核心开关；不要让新用户误以为可选生态与产品基础能力是一回事。
6. **厂商消费动作**：额度页的重置卡、自动重置、使用积分需单独确认；不能以「只剩额度卡」来声称已是只读轻量用量。

这些都是观察和建议；没有真实模型请求、原版 GUI 全流程操作或用户频率调查的验收证据。截图留在本机 `.tiny/audit-2026-10-19/`，包含六个不含账号信息的旧版界面截图和安装镜像截图，未把账号页截图或账号值写入本清单。
