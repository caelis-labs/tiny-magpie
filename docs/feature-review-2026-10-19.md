# tiny-magpie 功能边界（2026-10-19 用户确认）

本轮替代先前的人工复核草案。用户明确：低频独立功能移除，不收进高级设置；Jev 指通过网关调用 TypeSafe 分类 API，**不需要智能路由**。完成施工后先验收本地 Dev，用户确认后再发布首个稳定 Release。

## 保留并做全

| 核心区 | 保留内容 |
| --- | --- |
| 供应商 | 上游可用的各类订阅、API、自定义、中转和本地 Provider；插件追加；认证、刷新、账号发现、额度读取与迁移 |
| 模型 API | Chat/Responses/Anthropic/Gemini；TypeSafe/Jev System One 直接分类；Embedding/Rerank；既有流式、工具调用和多模态输入 |
| 路由 | 常规组、别名、账号/密钥选择、轮询/顺序/权重/额度、亲和、并发、限流、失败切换；不做意图推断或自动选择推理级别 |
| 网关 | 状态、地址、密钥、接入示例、LAN/TLS/CORS 与管理保护、密钥预算、必要的代理和鉴权配置 |
| 用量 | 额度、token、费用、tok/s、TTFT、耗时、错误和重试；复用上游账本与统计口径，不录制完整正文 |
| 插件 | 原 Provider 和网关插件协议、宿主、发现/安装/更新/故障信息；核心内置模块固定装配 |
| GUI/运维 | 简洁 GUI、托盘、Web、CLI、语言/主题/缩放/无障碍、启动行为、Tiny 自身更新及上游跟踪 |

## 移除

请求密钥/PII/自定义词和正则脱敏；独立隐私页；自定义字体与图标挑选；账号截图打码；内置功能开关面板；重置卡操作、自动重置、积分续用、签到、预热。此前已删的 Agent 管理、Library、会话浏览/日志导入、正文录制、云同步、公共工具服务、遥测及原版更新源继续保持移除。

旧配置字段和耦合上游类型可能留存，以维持文件格式与合并成本；它们不能恢复被移除的产品行为。日志凭证清理、安全存储、网络鉴权和正常费用统计保留。

## 界面与兼容

供应商、路由、网关、用量、插件为主功能区。账号发现和禁用模型归供应商。设置收敛到常规与连接所需项；移除隐私、模型、额度和 About 的独立配置页及空标题。路由组位于实时诊断之前。

System One handler、分类模型发现标头与调用示例恢复自已集成上游。Embedding/Rerank 后端端点已存在于上游；Tiny 新增的薄 GUI 展示和调用示例复用现有 vendor 缓存、转发和计费，单独展示，不加入聊天模型列表，不自创公共插件/发现协议，不默认混合不同向量空间。

本轮不合并新的上游区间；已集成版本仍以 `UPSTREAM.json` 为准。验证区分离线 fixture、源码测试、跨平台编译、macOS 实机 Dev 和真实账号使用。Dev 验收前不发布正式版。
