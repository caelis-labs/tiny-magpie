# tiny-magpie 0.2.0

The first stable Tiny release focuses on a multi-Provider model gateway with a compact desktop and Web GUI. The maintainer accepted the local gateway-core Dev; publication still requires the exact-source CI and signed macOS artifact checks.

- Keep subscription/API/custom/local Providers, multiple subscription accounts, ordinary cross-Provider routing groups, quota-aware scheduling and fallback. A group can combine a subscription model with API and relay channels. Provider and gateway plugin protocols remain upstream-compatible.
- Restore explicit TypeSafe/Jev System One calls. Embedding and Rerank use the existing upstream forwarding endpoints, with separate model inventory and examples in the GUI. Tiny does not use classifiers for intelligent routing.
- Keep allowance, token and estimated-cost information, output token speed and first-token latency. The tray shows Allowances when a quota/balance/error card is available, following upstream. Unknown prices remain unpriced. Header/tray bird sizing, narrow timing cards and subscription-settings card spacing are corrected.
- Remove the privacy/redaction product, font picker, full request-body retention, reset/check-in/automatic-credit spending and built-in feature switchboard. Core gateway plugins stay enabled. Retained legacy configuration fields cannot reactivate removed products.
- Default to Tiny's Stable update channel. Explicit Preview preferences are preserved. Checking never downloads or restarts; downloading and restarting require separate actions. Tiny never uses Magpie's app feed.

MIT licensing, upstream notices and integrated baseline `d783df46cbac9021e26a6bd71ca0b55544552eb2` are retained. The multi-account/group routing and plugin implementations remain upstream's.

## Install and update

macOS: open the Apple Silicon DMG and drag the app to Applications. macOS app/DMG use Developer ID signing, notarization and stapled tickets. Windows amd64/arm64 `.exe` and Linux amd64/arm64 executables remain unsigned. Five corresponding standalone CLI downloads, source/build evidence and SHA256SUMS complete the existing 19-asset matrix. Intel macOS is omitted.

Version 0.1.2 needs one manual DMG upgrade to gain the updater. Newer Tiny builds can check Tiny's own releases. Do not share a profile with original Magpie.

## Evidence and limits

Local acceptance covers 51 retained Go test packages with Bun 1.4.2, 67 bidirectional protocol fixture comparisons, 70 Chromium/WebKit cases, focused race tests, three-platform vet/builds and isolated native macOS Dev interaction. Release CI repeats its gates on the tagged source. Native Windows/Linux GUI/install/update and live vendor accounts or third-party plugin releases have not been independently accepted in this revision. API/subscription features are inherited and fixture-tested; these results do not establish every vendor's current live behavior.

The macOS permission review verifies client-owned tool handoff. The original Accessibility/screen-recording/Automation prompt incident was not reproduced. Tiny's administrator update prompt now uses Tiny's name; it does not claim to fix that historical TCC event.
