# tiny-magpie 0.3.1

- Fix the tray panel's Agent tab: clicking it opens the Agent list, and the selected tab survives reload. Empty Allowances falls back to Agents.
- Keep slow Windows update downloads running while bytes arrive; cancel responses only after two minutes without byte progress. Cancellation, integrity checks and replacement safeguards remain.
- Add release-please version PRs and changelogs. Merging a checked version PR creates a Tiny tag and draft; the existing release workflow validates, signs, notarizes and publishes the original 19-asset matrix.

Validation uses isolated profiles, simulated APIs and the retained cross-platform CI gates. It does not access live Agent/account state. Native Windows/Linux GUI and update installation, current vendor accounts and clean-machine installation remain separate acceptance limits. macOS Apple Silicon distributions are signed and notarized; Windows/Linux remain unsigned.
