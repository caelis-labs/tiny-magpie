# tiny-magpie 0.3.0

Agent model switching returns in a reduced Agents page. Detect installed Agents, connect or disconnect the gateway with upstream configuration restoration, switch models and reasoning effort, choose Claude tiers, and control model-list visibility/order. Installation, Agent updates, Profiles, sign-in, memories, subagent orchestration and optimization menus stay outside Tiny.

- Integrate the complete 203-commit upstream interval through `ba319a7587923fc7a4ea3859658244d591261a59`. Keep upstream Provider authentication, model protocols, multi-account routing and gateway plugin hosts.
- Fold detailed Provider and group configuration into Advanced. Keep the original controls and saved semantics available without putting every option in the initial setup path.
- Preserve Tiny's independent identity, configuration and update feed. Keep removed media services, intent routing, privacy product, sessions, Library, account-switching jobs and upstream app updates unavailable.
- Background catalog updates and configuration follow-ups apply only to Agents explicitly managed by this Tiny profile, preserving other installations and disconnected Agents.
- Provider renames and removals keep connected Agent model references usable through upstream configuration writers.
- Agent drift checks no longer read history/logs. Codex model writes do not reconstruct session providers. Mixed plugins retain their gateway facets without executing Agent extensions.

MIT licensing, upstream notices and pinned-source metadata are included. macOS Apple Silicon app, CLI and DMG use Developer ID signing and notarization. Windows/Linux amd64 and arm64 desktop/CLI files remain unsigned. Intel macOS remains omitted. The release contains the existing 19-asset matrix, including build evidence, notarization receipts and SHA256SUMS.

## Evidence and limits

The reviewed candidate passes the retained cross-platform CI gates, 67 bidirectional protocol fixture comparisons, 84 Chromium/WebKit cases across five languages, isolated Agent configuration/restore tests and focused race checks. The six independent review regressions first failed against the pre-fix implementation. Release CI repeats its gates on the tagged source before packaging and publication.

CUA inspected and switched a model in a synthetic local Agent fixture and inspected the folded group editor. Real Agent/account interactions, current third-party plugin releases, native Windows/Linux GUI/install/update, and clean-machine installation have not been independently accepted in this revision. These are inherited, source-reviewed and fixture-tested capabilities; fixture results do not establish every vendor's current live behavior. Neither installed application nor live Agent state was modified during validation.
